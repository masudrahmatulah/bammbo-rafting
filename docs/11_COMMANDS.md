# 11 — Commands

Pemilik perintah. Semua dokumen lain merujuk ke sini (jangan salin perintah ini di dokumen lain).

| Tujuan | Perintah |
|---|---|
| Jalankan server dev | `npm run dev` |
| Build production | `npm run build` |
| Jalankan test (unit + integrasi) | `npm run test` |
| Jalankan E2E test (Playwright) | `npm run test:e2e` |
| Migrasi dev (buat & terapkan migrasi baru) | `npx prisma migrate dev` |
| Migrasi deploy (production) ⚠️ | `npx prisma migrate deploy` |
| Seed data contoh | `npx prisma db seed` |
| Lint | `npm run lint` |
| Buka Prisma Studio (inspeksi data) | `npx prisma studio` |
